# ブロック崩し (Pygame)

## セットアップ
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 実行
```bash
python main.py
```

## 操作
| キー | 動作 |
|---|---|
| ← / → (A / D) | パドル移動 |
| SPACE | ボール発射 |
| P | 一時停止 / 再開 |
| R | ゲームオーバー・クリア後にリトライ |
| ESC | 終了 |

## テスト
```bash
pytest
```
